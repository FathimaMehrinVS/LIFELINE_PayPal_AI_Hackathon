# Demo script (under 3 minutes)

Record only what works on the day. Check [integration-status.md](integration-status.md) first, and remove any line
that has not been shown working. Use an invented situation. Open the live app a minute early: the free Render plan
sleeps when idle.

| Time | Screen | Show | Say |
|---|---|---|---|
| 0:00 | Home | The headline | "Small NGOs receive emergency requests as messy messages. LIFELINE turns one into a plan an NGO can approve and a donor can fund." |
| 0:15 | Request Assistance | One question per screen: speak or type, then where, how many, how urgent | "Someone in a crisis shouldn't face a long form. Each screen asks one thing." |
| 0:40 | Did we get this right? | The AI summary, then tap the follow-up questions | "AI pulls out the facts and asks only what blocks a decision. 'Not sure' is fine: nothing is guessed." |
| 1:00 | Assistance Cases | The case, its route and basket | "Rules compare delivery routes and cap the basket. The AI only explains." |
| 1:15 | Suppliers | The verification checklist on one supplier | "A supplier can only receive orders after six recorded checks, each with evidence." |
| 1:30 | Assistance Cases | Choose an approved supplier, Approve, confirm | "A person decides. AI can't approve anything or move money." |
| 1:45 | Approved Plans | The plan, with amounts in the viewer's currency | "Donors see the need, items, cost and progress. Never a name, address or the family's words." |
| 2:00 | PayPal Sandbox | Pay as the Sandbox buyer, then the confirmation | "Our server confirms the capture with PayPal, and PayPal's signed webhook confirms it again." |
| 2:20 | Payments | The captured donation, and supplier payments shown separately | "A donation is never shown as a supplier payment or a delivery." |
| 2:35 | Delivery Tracking | NGO creates the pickup code; partner enters the family's code at handover; NGO confirms | "The NGO gives the family a one-time code. Only the right family can give it to the partner, so the handover is proven." |
| 2:50 | Audit Logs | Recent events | "Every approval and change is recorded. Simulated steps are labelled." |
| 2:55 | Close | Home | "AI understands, rules verify, NGOs decide, donors fund." |
