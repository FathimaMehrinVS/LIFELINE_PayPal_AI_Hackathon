# Channel3 integration — Member 3

Product discovery across online retailers: search essentials, compare price, availability and purchase links.
Reads `CHANNEL3_API_KEY` from `src/config/env.ts`. Check the Channel3 docs for the current endpoint and
request format, and track credit usage (the hackathon allowance is limited).

Channel3 results do not prove a product is physically available in a crisis-affected area. Always show them
next to the verified local registry (synthetic in the demo) and mark each item with `source`.
